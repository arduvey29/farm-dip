# Farm Dip Shopify theme

This folder is the Shopify theme for Farm Dip, built from the Next.js site in this repo. It has the same look, fonts, animations and words. The home page, header, footer and product page are editable in Shopify's theme editor. The other pages are fixed layouts whose text is edited in code.

## What is in here

| Folder | What it holds |
| --- | --- |
| `layout/` | The page shell (`theme.liquid`) and the "opening soon" shell (`password.liquid`) |
| `sections/` | Header, footer, cart drawer, the home sections, product page, shop, cart, blog, search, FAQ and the static pages |
| `snippets/` | Icons, size card, cart lines, the drips, and the illustrations (Rani, the eight scenes) |
| `templates/` | Which sections each page uses, filled with the site's own content |
| `config/` | Theme settings: contact details, FSSAI, the lab report, social links |
| `assets/` | Generated by `npm run theme:build` (CSS, JavaScript, fonts, images, video) |
| `src/` | The theme's own CSS and JavaScript, compiled into `assets/` |
| `setup/` | Store content to load once: the product CSV, product images, blog posts and policies |

## Commands (run from the repo root)

```bash
npm run theme:build       # compile assets/farm-dip.css and farm-dip.js, copy fonts and images
npm run theme:check       # build, then Shopify's theme checker
npm run theme:dev         # build, then a live preview on your store (asks you to log in once)
npm run theme:push        # build, then upload as a new unpublished theme
npm run theme:templates   # rewrite templates/ and setup/ from src/data (overwrites theme-editor changes in this copy)
npm run shopify:setup     # create the product, pages, blog posts, policies, FIRSTJAR and India shipping (skips what exists)
npm run theme:upload -- <themeId> <file in shopify/>...   # upload files with the API key when the CLI login has expired
```

`shopify:setup` and `theme:upload` read `.env.shopify` (git-ignored): `SHOPIFY_STORE`, `SHOPIFY_STORE_PASSWORD`, and the Client ID and Secret of the "Farm Dip" app in the Dev Dashboard, installed on the store. The live theme is #168508555426 on qqcs2d-fz.myshopify.com.

The Shopify CLI must be installed: `npm i -g @shopify/cli@latest`. Add `--store your-store.myshopify.com` the first time, for example `npx shopify theme push --path shopify --store farm-dip.myshopify.com --unpublished` after `npm run theme:build`.

**Fonts.** Author and General Sans (Fontshare, ITF Free Font License) may be self-hosted on the store but not redistributed. `theme:build` copies them into `assets/` from `src/assets/fonts/fontshare/`. They are git-ignored, so never commit them.

## One-time store setup

Do these in the Shopify admin (the left menu; **Settings** is the gear at the bottom left).

1. **Store details.** Settings > General: store name "Farm Dip", legal business name, address, phone, contact email. Currency: Indian Rupee. Time zone: (GMT+05:30) Kolkata. Unit system: metric, kilograms.
2. **Markets.** Settings > Markets: keep India as the only market.
3. **Taxes.** Settings > **Taxes and duties**:
   - Under "Manage sales tax collection", click **India**, then **Collect sales tax**, enter the GSTIN and save.
   - On the same page, tick **Include sales tax in product price and shipping rate** (our prices include GST). Save.
   - For the GST rate on ghee (HSN 0405), ask the client's CA. If Shopify's default rate for India is not that rate, create a collection called "Ghee" (Products > Collections > Add collection, add the product manually), then in Taxes and duties > India > **Tax rates and exemptions** > **Product overrides** > **Add override**, pick that collection and enter the rate.
   - If you cannot see "Taxes and duties", you are probably in the Partner Dashboard rather than the store admin, or logged in as staff without the Settings permission. Open the store's admin (`your-store.myshopify.com/admin`) as the owner, or type "taxes" in the admin's search bar at the top.
4. **Shipping.** Settings > Shipping and delivery > General shipping rates: one zone, India. Add a rate "Standard" of ₹79 with the condition "order price ₹0 to ₹998.99", and a rate "Free shipping" of ₹0 for orders from ₹999. Check the package weight.
5. **Payments.** Settings > Payments: Shopify Payments is not available in India. Add **Razorpay** (or Cashfree or PayU) as the payment provider; it needs the business PAN, GSTIN, a bank account and a live site with policies. Under "Manual payment methods", add **Cash on Delivery (COD)**. On a development store, test with the "Bogus Gateway".
6. **Checkout.** Settings > Checkout: customer contact method "Phone number or email"; checkout layout "Three-page"; under "Customize", set the colours to ghee gold `#f5bf47` and ink `#231b1e` and upload the badge (`assets/farm-dip-badge.svg`, or a PNG of it).
7. **Policies.** Settings > Policies: paste `setup/policies/refund.html`, `privacy.html`, `terms.html` and `shipping.html` (use the editor's "Show HTML" button).
8. **Notifications.** Settings > Notifications: set the sender email and add the logo.
9. **Product.** Products > Import: upload `setup/products.csv`. It creates "Pure Desi Buffalo Ghee" with 500 ml, 1 L and 5 L at ₹1,350 / ₹2,210 / ₹9,900 (MRP ₹1,699 / ₹2,799 / ₹12,499) and the five images. The images load from GitHub, so the repo must be pushed first. Check the weights (they are estimates) and the stock settings after import.
10. **Pages.** Online Store > Pages > Add page, for each row below. Leave the content empty and choose the template on the right:

    | Title | Template |
    | --- | --- |
    | Our story | page.about |
    | How it's made | page.how-its-made |
    | Lab reports | page.lab-reports |
    | Contact | page.contact |
    | FAQ | page.faq |
    | Track your order | page.track-order |

    Keep the URL handles `about`, `how-its-made`, `lab-reports`, `contact`, `faq` and `track-order`: the theme links to them.
11. **Blog.** Online Store > Blog posts > Manage blogs > Add blog, title "Know your ghee", handle `know-your-ghee`. Then add each post in `setup/blog/`: the title, handle, tags and excerpt are in the comment at the top of each file; paste the rest with "Show HTML"; upload the matching PNG as the featured image.
12. **Menus.** Online Store > Navigation. The theme shows the right links even without menus. To edit them yourself, create menus and choose them in the theme editor (Header > Main menu, Footer > Column 1 to 4).
13. **Discounts.** Discounts > Create discount > Amount off order: code `FIRSTJAR`, 10%.
14. **Theme.** Upload the theme (`npm run theme:push`), open Online Store > Themes > the new theme > **Customize** and check:
    - Theme settings (the brush icon): contact details, FSSAI, the lab report link (upload the PDF in Content > Files and paste its link) and social links.
    - Home page > Hero: pick the product; optionally upload the video in Content > Files and choose it.
    Then click **Publish**.
15. **Apps.** Judge.me (reviews, then add its block to the product page), Shiprocket (couriers and tracking; put its tracking page in Header > "Track your order" link), Google & YouTube, Facebook & Instagram.
16. **Domain and launch.** Settings > Domains > Connect existing domain: an A record to `23.227.38.65` and a CNAME for `www` to `shops.myshopify.com`. Place test orders (online payment and COD), then remove the password in Online Store > Preferences.

## How the pieces map to the Next site

See [../SHOPIFY.md](../SHOPIFY.md). The CSS is compiled from `src/app/globals.css` and the motion from `src/lib/motion.ts`, so design changes made in the Next site carry over with `npm run theme:build`. The static page sections (`page-*.liquid`) and the illustrations in `snippets/` were copied from the site's rendered pages; re-copy them by hand if those pages change.
